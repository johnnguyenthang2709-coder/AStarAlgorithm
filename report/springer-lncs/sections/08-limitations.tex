\section{Limitations and Threats to Validity}
\paragraph{Model validity.} The simulator assumes static obstacles, ideal localization, reversible point motion, and reliable observation geometry. It has no probabilistic sensing, pose drift, dynamic obstacles, or finite-footprint configuration-space model. Conservative sampled sensing can leave narrow occluded regions undiscovered. An accumulated free-space union is not equivalent to seeing the entire sensing disk. The frontier policy uses a finite candidate set and budgets; success on mazes and indoor fixtures does not establish completeness on arbitrary polygonal worlds.

\paragraph{Scope of guarantees.} Graph-optimal A* paths can be longer than a continuously optimized path because relevant vertices are absent. The observed-parent return bound requires verified reversible recorded entry, appropriate endpoints, and locked execution. It is not a proof of universal BAR identification or optimal total online travel. The assigned paper's approximate-path and restricted convergence arguments concern its own models; they cannot be transferred to this architecture by citation. The project's architecture supports the BAR-inspired problem under these explicit restrictions, rather than implementing every geometric mechanism in the publication.

\paragraph{Comparison validity.} The local study shares observed information but not planning graphs. Permissive and strict boundary conventions yield materially different interpretations. The primary point model cannot validate a disk robot. The source's coordinate transitions and logged ASPs do not expose a common continuous executed trajectory, so the end-to-end comparison remains gated. Our A* adapter is also different from the paper's grid baseline; this is not a reproduction of its published numerical tables. No superiority claim follows from local runtime components or selected examples.

\paragraph{Sampling and timing.} One road network and convenience robot maps restrict external validity. Correlated decisions, overlapping held-out geometry, and only 21 eligible nontrivial requests limit statistical interpretation. The prospective extension reduces outcome-driven selection but does not create independent random trials. Windows scheduling, Python versions, compiler settings, batch averaging, and unmatched computation boundaries influence time. Raw repetitions and ranges improve auditability but do not eliminate these confounders. The report therefore uses paired descriptive statistics, without significance claims or transferable speedup guarantees.

\paragraph{Reproducibility.} Frozen regression records report four C++ suites, 169 Python tests, and 34 frontend tests, plus build/lint success. These do not prove optimal exploration. Report validation checks hashes and descriptive statistics without changing results. Author and affiliation fields remain configurable because submission metadata is unverified.
